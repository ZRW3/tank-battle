# 坦克大战

基于 HTML5 Canvas 的经典坦克大战网页游戏，纯原生 JavaScript 实现，无需任何依赖。

## 快速开始

直接用浏览器打开 `index.html` 即可开始游戏。

## 操作方式

| 按键 | 功能 |
|------|------|
| `↑ ↓ ← →` 或 `W S A D` | 移动坦克 |
| `空格` 或 `J` | 发射子弹 |
| `R` | 游戏结束后重新开始 |

## 游戏规则

### 基本玩法
- 控制你的绿色坦克，消灭所有敌方坦克即可通关进入下一关卡。
- 每关地图随机生成，关卡越高，敌人越多、速度越快。
- 初始生命 **3** 条，被敌人子弹击中或与敌人碰撞会损失生命。

### 地图元素
| 元素 | 颜色 | 说明 |
|------|------|------|
| 砖墙 | 棕色 | 可被子弹摧毁 |
| 钢墙 | 灰色 | 不可摧毁 |

### 敌人类型
| 类型 | 颜色 | 特点 | 击杀分数 |
|------|------|------|----------|
| 基础坦克 | 红色 | 标准属性 | 100 |
| 快速坦克 | 橙色 | 移动和射速更快 | 200 |
| 重型坦克 | 深红+金边 | 需击中两次才能摧毁 | 300 |

### 道具系统
道具会随机出现在地图上，拾取后立即生效：

| 图标 | 道具 | 效果 |
|------|------|------|
| **S** | 护盾 | 免疫一次伤害 |
| **F** | 冰冻 | 减速所有敌人 3 秒 |
| **B** | 炸弹 | 瞬间消灭所有敌人并获得分数 |

### 无敌时间
每次被击中或复活后有短暂的无敌时间（闪烁表示），期间不受伤害。

### 过关条件
消灭当前关卡所有敌人即可自动进入下一关。

## 技术实现

- **Canvas 渲染**：所有图形通过 HTML5 Canvas 绘制
- **碰撞检测**：基于边界盒的像素级碰撞检测
- **地图生成**：3 种预制布局循环使用，每关随机选择
- **粒子系统**：击杀敌人和摧毁砖墙时的粒子特效
